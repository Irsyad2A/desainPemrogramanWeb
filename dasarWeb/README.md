# Jobsheet 1 — Desain dan Pemrograman Web

Repository ini berisi hasil pengerjaan **Jobsheet 1** pada mata kuliah **Desain dan Pemrograman Web**.

## Materi yang Dipelajari

Pada jobsheet ini saya mempelajari dasar HTML, mulai dari struktur dokumen sampai pembuatan form. Materi yang dikerjakan meliputi:

- Struktur dasar HTML
- Heading dan paragraf
- Formatting teks
- HTML Entities
- List
- Gambar
- Hyperlink
- Tabel dan pengaturan tabel
- Form dan berbagai jenis input
- Pengiriman data menggunakan `GET` dan `POST`

## Daftar File

| File | Keterangan |
|---|---|
| `hello.html` | Latihan struktur dasar HTML. |
| `heading.html` | Latihan heading `<h1>` sampai `<h6>`. |
| `paragraf.html` | Membuat paragraf menggunakan `<p>`. |
| `paragrafAlign.html` | Mengatur perataan paragraf menggunakan `align`. |
| `font.html` | Latihan formatting teks. |
| `garishorizontal.html` | Membuat garis horizontal menggunakan `<hr>`. |
| `Karakter.html` | Menampilkan karakter khusus menggunakan HTML Entities. |
| `list.html` | Membuat ordered dan unordered list. |
| `gambar.html` | Menampilkan gambar menggunakan `<img>`. |
| `macamLink.html` | Latihan berbagai jenis hyperlink. |
| `tugasLink.html` | Tugas membuat gambar sebagai hyperlink. |
| `warna.html` | Latihan pengaturan warna pada halaman HTML. |
| `buatTabel.html` | Membuat dan mengatur tabel, termasuk `colspan` dan `rowspan`. |
| `buatForm.html` | Membuat form dengan text, radio, checkbox, select, password, textarea, serta `GET` dan `POST`. |

## Cara Menjalankan

Project dapat dijalankan menggunakan Laragon.

Simpan folder project di:

```text
C:\laragon\www\dasarWeb
````

Kemudian buka file melalui browser:

```text
http://localhost/dasarWeb/<nama_file>.html
```

Contoh:

```text
http://localhost/dasarWeb/buatForm.html
```

## Hasil Pembelajaran

Setelah menyelesaikan Jobsheet 1, saya memahami dasar penggunaan HTML untuk membuat halaman web sederhana. Saya juga memahami fungsi dari beberapa tag HTML dan bagaimana setiap elemen digunakan untuk menyusun konten, menampilkan gambar dan link, membuat tabel, serta menerima input dari pengguna melalui form.

Selain itu, saya memahami perbedaan dasar antara method `GET` dan `POST`. Pada `GET`, data form terlihat pada URL setelah dikirim, sedangkan pada `POST`, data tidak ditampilkan pada URL.
